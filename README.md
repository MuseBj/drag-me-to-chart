# drag-me-to-chart

> *“Cursed to assemble dashboards with your mouse forever.”*

A modern, highly-interactive WYSIWYG drag-and-drop dashboard studio built with React 19, TypeScript, Tailwind CSS v4, and Apache ECharts.

---

## ✨ Features

- 🖱️ **Drag & Drop Canvas** — Freely arrange, reorder, and organize your dashboard layout in real time.
- 📊 **Apache ECharts Powered** — Rich visualizations including line, bar, pie, radar, scatter, and gauge charts.
- 🧩 **Modular Widget Library** — KPI stat cards, interactive data tables, notification banners, and chart widgets.
- 🎨 **Theme & Palette Switcher** — Instantly preview and apply curated color palettes and dark/light accents.
- 📋 **Preset Industry Templates** — One-click starter layouts for SaaS, Healthcare/Medical, and more.
- 📸 **Instant Export & Copy** — Export your dashboard as high-resolution PNGs or copy directly to your clipboard.
- 🤖 **LLM Prompt Generator** — Export layout specifications and data schemas into prompts tailored for LLM code generation.
- ⚡ **Lightning Fast Tooling** — Powered by Vite 8 and Oxlint.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+ recommended)
- `npm`

### Installation

```bash
# Clone the repository
git clone https://github.com/MuseBj/drag-me-to-chart.git

# Navigate into the project directory
cd drag-me-to-chart

# Install dependencies
npm install
```

### Development

Run the Vite development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build

Create an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

### Linting

Run Oxlint:

```bash
npm run lint
```
